# why-are-we-here

## Introduction

I did not need programming to make my recent short film, Source. As a student from a Design for Art Direction background, I am more familiar with images, moving image, collage and visual storytelling than with code. For Source, I used AI-generated imagery to create a visual journey from futuristic digital landscapes and glowing organic forms to Buddhist imagery and a traditional Chinese street filled with red lanterns. I could describe the atmosphere I wanted, generate images, select the ones I liked, edit them together and add sound without writing a single line of code.

This made me question why I am learning programming at all. If AI can increasingly turn an English description into working code, perhaps learning how to type code will become less important. I do not think the answer is that I need to become better at coding than AI. Instead, I want to understand what happens between an idea and a system. I do not need programming to use AI creatively. That is precisely why I am interested in learning it.

## Why am I learning programming?

Making Source helped me recognise a difference between describing something and specifying something.

In my creative process, I can use words such as “peaceful,” “futuristic,” or “traditional Chinese” to communicate a visual direction to AI. This allows me to explore possibilities quickly without understanding the technology behind the process. However, these descriptions mainly produce individual visual results. I can select and edit them, but I am not necessarily defining how they relate to each other.

Programming offers a different way of working. Instead of only describing what something should look like, I can define how it should behave. And I see it as a transition from “make this” to “make this happen under these conditions.” AI may be able to generate the code for me, but I still need to understand what I am asking the code to do.
